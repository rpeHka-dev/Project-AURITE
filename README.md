# Project AURITE

**Project AURITE** — это пиксельный 2D градостроительный симулятор с элементами выживания на ледяной планете. Игрок управляет колонией, которая добывает редкий металл **аурит** для Земли, борется с холодом и выполняет ежемесячную квоту.

---

## О проекте

**Планета Борей** — ледяной мир на краю обитаемой зоны. Под слоем вечной мерзлоты скрывается аурит — металл с уникальной кристаллической решёткой, сохраняющей сверхпроводимость при абсолютном нуле. Земля отправила команду под вашим управлением, чтобы основать колонию для добычи аурита. Вы должны выполнять поставки металла вовремя, любой ценой.

**Ключевая особенность:** в отличие от большинства градостроительных симуляторов, здесь строительство - не цель, а инструмент достижения ее достижения - поставки квоты.

### Главные механики 

    Гексагональное поле, строительство/удаление зданий.
    Добыча ресурсов, время (пауза, ускорение), квота аурита.
    Распределение тепла, фундаменты, шкала недовольства.
